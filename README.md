# Subha Artha Production House | Photography, Cinema & Visuals

A high-performance, visually immersive fine art photography and cinema booking web application designed for **Subha Artha Production House**, led by **Sabyasachi Banerjee**—documenting timeless weddings, pre-weddings, haute couture editorials, and international celebrations worldwide.

---

## Technical Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS (Luxury Dark Palette `#0A0A0B`, `#121214`, `#D4AF37`)
- **Typography**: Cormorant Garamond / Playfair Display & Plus Jakarta Sans
- **Animations**: Framer Motion (subtle scroll reveals, layout animations, smooth transitions)
- **Icons**: Lucide React + Custom SVG Brandmarks
- **Audio Synthesis**: Web Audio API ambient analog projector soundscape
- **Interactive FX**: Canvas Confetti celebratory booking transmission

---

## Core Features
1. **Dynamic Showcase Hero**: Full-viewport cross-fade carousel with Ken Burns motion, booking calendar indicators, and instant specialty jump filters.
2. **Artist Spotlight & Statement**: Introduction of Principal Artist Sabyasachi Banerjee, his philosophy on natural light and emotional preservation, with interactive perspective switching (Cinematography, Live Direction, and Studio Sound).
3. **Filterable Masonry Portfolio**: Category tabs (*All Works, Weddings, Pre-Wedding & Couples, Editorial & Fashion, Corporate & Galas*) with Framer Motion layout transitions.
4. **Interactive Lightbox Modal**:
   - Fullscreen frame inspector with keyboard navigation (`←`, `→`, `ESC`, `I` for specs).
   - EXIF Technical Specs Drawer (Nikon mirrorless, Leica rangefinders, lens focal length, aperture, shutter speed, ISO).
   - Direct *"Inquire For Similar Commission"* action pre-filling the booking form.
5. **Flagship Case Studies**: Side-by-side split editorial spreads with curated photo sequences and shoot color swatches.
6. **Before / After Retouching Alchemy**: Draggable split-slider comparing uncompressed sensor RAW files against Sabyasachi's signature fine-art master color grade.
7. **Tiered Collections & Currency Switcher**: 4 comprehensive investment tiers (*Intimate Heirloom, Grand Celebration, Multi-Day Odyssey, Bespoke Atelier*) with live conversion between USD ($), EUR (€), GBP (£), INR (₹), and CAD (CA$).
8. **Interactive Bespoke Add-Ons Estimator**: Real-time investment calculation for 35mm/120mm film rolls, 4K aerial drone suites, parent albums, and 7-day rush delivery.
9. **Worldwide Destination Tour Itinerary**: 2026/2027 calendar residency (Lake Como, Paris, Scottish Highlands, Amalfi, Kyoto, Swiss Alps) with built-in travel logistics fee waivers.
10. **Bespoke Heirloom Albums**: 3D-style virtual open-book layflat album simulator with genuine Tuscan leather, French velvet, and Belgian linen swatches.
11. **Behind The Lens Optical Toolkit**: Detailed inventory of Sabyasachi's Nikon Z9/Z8 bodies, NIKKOR f/1.2 primes, Mavic 3 Pro Cine drone, and Profoto strobes.
12. **Client Reviews & Press Features**: Testimonial carousel and editorial publication accolades (*Vogue, Harper's Bazaar, Brides, Rangefinder, Junebug Weddings*).
13. **Comprehensive Booking & Reservation System**: Full inquiry validation, event date picker, scope selector, vision field, and champagne confetti celebration.
14. **Private Client Vault™ Preview**: Interactive demo of the private client delivery suite with favorites selection, 100% zoom, and high-res ZIP downloads.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Souyash/Photography.git
cd Photography

# Install dependencies
npm install

# Run the development server
npm run dev

# Run TypeScript check and production build
npm run build
```
